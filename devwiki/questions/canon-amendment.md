# Canon amendment

## Decided: canon authority

Canonical state is authoritative, not immutable. It is never overridden by derived observations, simulation, projections, or resolution processes. The world's author has the final say and may change canonical state through an explicit, recorded authorial amendment.

An authorial amendment is part of the world's history, retains provenance, and takes precedence over earlier canonical values, including imported ones.

## Open: representation of authorial amendments

The representation of an authorial amendment remains open. In particular:

- Should an amendment be represented as an in-place canonical change plus an event, an overlay layer that outranks imported and simulated layers, or another mechanism?
- How should dependent derived values be invalidated after an amendment? This relates to [[devwiki/experiments/invalidation-reconciliation]].
- How should an edited Markdown note become an explicit authorial amendment? See [[devwiki/questions/obsidian-markdown-interface]].

These are representation questions, not a decision to adopt any particular mechanism.
